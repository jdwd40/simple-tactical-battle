# Contract API and units

`src/contracts/index.ts` is the presentation/AI entry point: public readonly types, `DUEL_RULES`, `DUEL_MAP`, `DUEL_PUBLIC_SCENARIO`, `SAMPLE_PLAYER_OBSERVATION`, `cellCentre`, `isMapCell`, `isAsteroidCell` and `aftermathWindowBound`. Public ship specs are `DUEL_RULES.ships`; own gauges/equipment come from `SideObservation.ownShip`. The sample is a static schema example, not a running game or an engine initializer.

Engine/application code explicitly imports `src/contracts/private.ts` for `Scenario`, `SimulationState`, `ShipState`, `MissileState`, `PrivateKnowledge`, `RandomState`, `InternalEvent`, `AcceptedTurn`, `TurnResolution`, `TurnPresentation` and engine function signatures. `src/scenarios/private.ts` exports the authored `DUEL_SCENARIO`, validating `createScenario`, and whitelisted `publicScenario` projection. Never import these modules from UI/rendering or the AI planner. TypeScript does not enforce directory access restrictions; the barrel, explicit construction and boundary checks establish this seam.

`src/scenarios/rules.ts` contains the single millisecond/rate source `DUEL_CONFIG` and `createRuleset`. It rejects nonfinite, negative, fractional and unsafe numeric config, nonintegral tick durations/grants, energy beyond capacity and incompatible ship geometry. `createScenario` validates terrain/spawn geometry. Rules derive all tick clocks and fixed per-tick rates, then copy and recursively freeze JSON data. Tick duration is 100ms; a turn is 100 ticks. The automatic tail bound is `aftermathWindowBound(rules, remainingSurvivorAmmunition)`, default 2 windows without further launches. Diagnostic cutoff 200 is not a gameplay draw.

## Units

- `Cell` is a zero-based integer column/row. Columns/x increase right; rows/y increase down. The 20×20 public map contains solid asteroid cell rectangles.
- `Position` uses integer world units: 1000/cell, centre `(column*1000+500, row*1000+500)`. Ship/missile radii are 250/100; splash radius 750. Route cost is 1000 cardinal, 1414 diagonal. Segment progress is integer distance along the waypoint segment, retained across turns. The engine owns deterministic routing/sweeps and the preview implementation.
- Headings are integer milli-degrees clockwise from north in `[0,360000)`: north 0, east 90000, south 180000, west 270000. Initial ships face each other. Velocity is measured world units per tick; it is derived only from two distinct-tick observations.
- `Tick` is a nonnegative integer absolute simulation boundary. Turn indices start at zero. Clocks are ready/expire at the named absolute tick; no wall-clock data belongs here. Memory expires after 600 ticks. Current tracks have age/radius zero; stale age and uncertainty use elapsed ticks/public maximum speed and are clipped to public map bounds by the engine. Hostile missile memory has no aim; own telemetry may include its own aim.
- Energy is integer milli-energy (1000 = one display unit); regen/propulsion/cloak grants are 200/100/300 milli per default tick. Hull, shields, ammunition and damage are integer display values. Only energy is scaled. Gauge maxima are supplied explicitly.
- Seeds and `RandomState`/`PlanOpponent` stream states are explicit uint32 numbers. Only the engine/planner consumes those streams; fixture/config helpers never draw randomness. Private missiles retain launch point and integer travelled distance so cross-turn interpolation can retain progress without cumulative rounding drift.

## Controller and information obligations

`GameController` is an interface only. `getView()` returns the same immutable reference until an update; `subscribe` returns an unsubscribe callback. `GameView.revision` increases on updates within an encounter and `encounterId` changes on restart. `setDraft`, atomic `commit(expectedTurnIndex)`, `playback`, `finishAssessment`, `abandon` and same/new-seed `restart` are the command surface. New seed entropy is an application responsibility, never an engine clock/random source. Commit returns accepted/rejected/ignored, including stale-turn and wrong-phase; double commitment must not resolve twice.

Planning supplies the draft, structural/conditional/warning issues and predicted own route. Validation/preview signatures accept only own observation and public map/rules, never hidden state. Successful activity breaks cloak; suppression and activity/unfunded latches are separate states. A conditional intent does not become a structural rejection because of hidden information.

Commit locks own orders. Execution exposes integer cursor bounds, known prefix frames/events and locked own orders; automatic execution carries only `reason: own-destroyed`. Replay scope is the latest player-committed turn and attached automatic aftermath, not an encounter-wide browser. The starting frame and each recorded tick are retained only through cursor. `endTick` is the scheduled known window boundary and may extend when an automatic window begins; it must not disclose a precomputed future window count. Interpolation may lag from n-1 to n only after n is known, with a current contact in both contiguous frames; never bridge unseen intervals.

`TurnPresentation` holds a complete observer-safe turn internally, but its future frames and assessment are **not** public API exports. When seeking before a reveal tick, the controller returns execution/prefix data and withholds end assessment/outcome, including when replaying from a completed encounter. Assessment is an own summary with safe action failure reasons. `ordnancePending: null` means no justified explanation, not knowledge of hidden absence. A nonnull explanation requires known own missiles or observed opposing destruction.

Terminal combat carries a reveal-timed outcome. Abandon is a distinct terminal `result.kind: abandoned`, awards no combat outcome and stops the session; restart creates fresh state. Aliases are stable through reacquisition within memory lifetime, and private ID mappings never cross the seam. No internal event is forwarded using a visibility flag: visible event payloads must be constructed explicitly. Neither unseen destruction nor future ending state may change validation, phase, available orders or public payloads.

These declarations do not implement controllers, simulation, order validation, pathfinding, sensing, combat or AI. Their runtime obligations require later engine/application regression tests. Public JSON roundtrips and hidden-spawn-equivalent scenario projection are covered now.
